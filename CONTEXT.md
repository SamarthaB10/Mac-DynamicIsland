# Mac Island

Mac Island keeps music controls, files, and saved text near the MacBook notch.

## Language

**Hub file**:
A file or folder shown in the Hub. Removing its entry does not delete a local source.

**Online file**:
A temporary copy received from a browser drop. The Hub keeps it while a drag or upload uses it, then deletes it when the entry is removed.
_Avoid_: Drive download, which stays on disk.

**Accepted drop**:
An outgoing drag that another app accepted. Acceptance does not mean that the receiving app has finished copying the file.

**Saved text**:
A text entry or complete web link kept on this Mac until the user removes it. It can have an optional title.

**Website notification**:
An alert that a selected website sends through the user's browser.

**Notifications**:
The area in the island that holds website notification cards. A bell identifies this area.

**Read notification**:
A website notification marked as read in the island. Its card stays in Notifications until dismissed.

**Dismissed notification**:
A website notification whose card the user removed from the island. Removal of its macOS alert and the change to its website read state can fail separately; the website item is not deleted.
